# 能力边界

## 目前不应宣称的能力

- 不是有质量绳/柔性杆：没有悬垂、绳质量惯性、弯曲扭转、传播波或结。
- 不是全场景自动接触：绳只对已配置的路线表面/guide 建模。
- 不是自动拓扑规划：不自动越侧、脱离/重接、穿孔搜索或绳自接触。
- 不是完整静摩擦：固定方向或速度正则化 Capstan 不等于精确粘着互补求解。
- 不是 GPU 插件：现有 C++ 状态和迭代不自动迁移到 MJX/Warp。
- 不是无限刚性绳：有限 k 与严格等长约束不同。
- 不是完整真实数字孪生：材料、孔口、阻尼、接触和预紧仍需标定。

## 案例中的特别边界

| 案例 | 可说明 | 不能据此推导 |
|---|---|---|
| 卷轴半径比 | 在显式理想 equality 下的圆周位移关系 | 摩擦自动实现精确无滑移 |
| 动滑轮 | 承载绳段、约 2:1 位移、传力 | 两轮转角必然严格 2:1 |
| Atwood 落地 | 落地前与理想模型对照，落地后松弛/接触 | 冲击后仍符合无碰撞闭式解 |
| Faive | 虚拟铰链与绳驱输入的不同传动映射 | 给定一样数值输入就有一样物理意义 |
| SpiRobs μ 扫描 | 摩擦对源端载荷与关节分配的敏感性 | 单靠仿真形状完成材料或摩擦辨识 |
| 孔口 guide | 已知孔口拓扑和折角损失 | 孔径、孔壁分布接触、卡滞和磨损 |
| ICRA 字母 | 中面非圆轮廓连续包络与被动传动 | 正式精度或真实自由落体抓握 benchmark |

## 已知数值风险

路线优化是局部、有暖启动的计算；残差较好不等于任意非凸表面的全局最短解。三角化、尖角、近零自由段和有限圆柱端面均需专门验证。已观察到圆柱离散长度率在某些整体刚体运动中的一致性误差，尚不能宣称所有后端都严格满足刚体不变性。

当前库注册表中可见某个配置名，不代表它在标准宿主上就有完整实现。例如 `implicit_compliant` 需要对应的内核扩展；无摩擦局部隐式模式也不是多绳+接触的统一非线性解。

## 如何继续扩展

先提出可区分的物理假设和最小验证，再增加代码。例如自动拓扑切换需要脱离/重接事件、分支连续性、能量与虚功验证；有质量绳应作为新增动力学层保留现有降阶模型，而不是把一个 μ 参数当成绳质量。
